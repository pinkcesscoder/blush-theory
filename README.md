# Blush Theory 💗

Blush Theory is a beauty-inspired e-commerce website I'm building as part of my journey into software development. I wanted to create something fun, feminine, and interactive while putting my HTML, CSS, and JavaScript skills into practice.

## Technologies Used
- HTML — Website structure and product information
- CSS — Layout, colors, and custom lip gloss designs
- JavaScript — Product interactions and shopping cart functionality

## Features So Far
- Custom-designed lip gloss product collection
- Interactive Add to Cart buttons
- Shopping cart that displays selected products

## Project Status
**Work in Progress**

I'm continuing to strengthen my programming fundamentals while learning how to build a more functional shopping experience.

## What I'm Learning
- Writing and organizing HTML and CSS
- Working with JavaScript variables, arrays, and functions
- Using event listeners and DOM manipulation
- Debugging and improving my code
- Using Git and GitHub for version control

Blush Theory is being developed and prepared for its first live website release.
